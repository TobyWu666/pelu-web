Windows 端

能在 Windows 上做出與 PeluMac 相當體驗的桌面 app(系統匣 / 通知 / 開機自啟動)。WPF、WinUI、Tauri、Electron、Flutter 等技術都歡迎討論。

Android 端

能在 Android 上實現對應的 Dashboard、Widget 與通知體驗。熟悉 Kotlin + Jetpack Compose 或跨平台框架皆可。

與 Apple 版的一致原則

資料屬於使用者、不蒐集、不打擾。同步方案可以用 Google Drive、Dropbox 或其他端到端方案,只要符合 Pelu 的隱私承諾就好。

合作方式都可談,沒有框框。完整一起打造 PeluWin / PeluDroid、開源協作、先寫個 prototype 玩玩看, 甚至你只是想聊聊產品方向或別的點子,都很歡迎。信件中可以附上你的背景、過往作品,或是你正在想的事。

為什麼做 Pelu

因為我自己也想要這個。

我每天都在用 Claude Code 與 Codex 寫程式,常常一忙起來就忘了剩多少額度,直到撞牆才發現自己被限速了。

市面上有一些方案,但要嘛要把資料丟到別人家伺服器、要嘛流程繁瑣。我想要一個「打開 iPhone 就看到」的版本,而且資料只屬於我自己。

所以,Pelu 出現了。

設計原則
  • 資料屬於使用者。沒有自家伺服器,沒有帳號,什麼都不蒐集。
  • 介面要安靜。不該打擾你的時候,連 1% 的存在感都不要有。
  • 尊重 Apple 生態。該用系統原生方案的時候,就不要自己造輪子。
  • 把細節做到位。排版、間距、動畫、文字,通通在意。
