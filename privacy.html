隱私政策

我們的隱私原則很簡單,只有一條:你的資料只屬於你。 Pelu app 沒有自家資料伺服器、沒有帳號系統,我們既看不到、也不持有你的使用資料。官網只做匿名瀏覽量統計。

一頁摘要

Pelu app 不知道你的任何事

  • Pelu app 沒有自家資料伺服器。所有資料同步靠 Apple iCloud,完全不會經過我們。
  • 沒有帳號要註冊。你不需要給我們 email、不需要設密碼。
  • 資料只放在你的 iCloud,只有你的 Apple ID 看得到,Apple 也不會分享給我們。
  • App 內沒有追蹤工具。沒有 Google Analytics、沒有廣告 SDK、沒有崩潰回報服務。網站只做匿名瀏覽量統計。
  • App Store 隱私標籤申報為「Data Not Collected」。Pelu 不會把資料傳給我們或第三方。

我們不蒐集什麼

下面這些東西永遠不會離開你的裝置,我們也沒有任何辦法看到:

你的用量百分比

Claude Code 與 Codex 的剩餘額度。

你花了多少錢

AI 工具的成本估算數字。

你 Mac 的名字

例如「Toby 的 MacBook」,只用於設定中的裝置列表。

通知 / 顯示偏好

你開了哪些通知、要不要顯示動態島。

30 天歷史

Pelu app 內的歷史紀錄,只存在你的 iPhone 上。

你的對話內容

我們只看「用了多少」這個數字,完全不會打開你和 AI 的對話。

你的資料去了哪裡

Pelu 的同步只走一條路,而且這條路上沒有我們:

  1. 第 1 步
    你的 Mac

    Pelu 在本機讀取 Claude Code 的 statusLine hook 寫出的用量檔,並透過 Codex 桌面 app 或 CLI 內附的 binary 取得 Codex 官方 quota;官方 quota 暫時讀不到時才退回本機 session 紀錄估算。整個過程都發生在你的 Mac 上。

  2. 第 2 步
    你的 iCloud

    透過 Apple 的 iCloud 同步,只有你的 Apple ID 看得到。

  3. 第 3 步
    你的 iPhone

    iPhone 把多台 Mac 中最近更新的用量畫進 Dashboard、Widget 與動態島。

中間沒有任何 Pelu 伺服器。我們從頭到尾沒辦法看到你的資料,也沒辦法把它賣給任何人。

放在哪、放多久

Pelu 只在三個地方留下資料,你可以隨時清除:

  • 你的 Mac:Pelu app 本身,以及它觀察到的最新用量數字。刪掉 Pelu 即移除。
  • 你的 iCloud:用於同步最近更新的用量與設定中的裝置列表。你可以在 iCloud 設定中隨時刪除。
  • 你的 iPhone:30 天歷史紀錄,只在 iPhone 本機。刪掉 Pelu app 一併移除。

移除 app 後,我們這邊不會留下任何備份——因為我們從一開始就沒拿到。

我們有用第三方嗎

Pelu app 不使用任何第三方分析、廣告、或崩潰回報服務。Mac 與 iOS 端只依賴下列原生 / 開源元件:

  • iCloud(CloudKit private database):把資料從你的 Mac 同步到你的 iPhone。
  • iOS 通知:在你授權後,當用量接近上限或週期重置時通知你。
  • Sparkle 自動更新:macOS 版本以 Sparkle 連到我們發布的 appcast.xml 檢查新版本,不會夾帶任何使用統計。

至於你用的 AI 工具(例如 Claude Code、Codex)各自的隱私政策,請依其官方規範。Pelu 只在你的裝置上讀取它們留下的用量數字(Claude Code 透過 statusLine hook、Codex 透過本機 binary 的官方 quota / fallback session 紀錄),絕不會把這些數字傳給任何第三方。

網站瀏覽統計

Pelu 官網會用我們自己的 Cloudflare Worker 記錄匿名瀏覽次數,目的是知道支援頁與下載頁是否真的有人使用。

  • 只保存日期、頁面路徑與加總次數。
  • 不設 cookie、不產生訪客 ID、不保存 IP 位址或 User-Agent。
  • 不使用 Google Analytics、Meta Pixel 或廣告追蹤工具。
  • 若瀏覽器啟用 Do Not Track,前端不會送出這筆瀏覽事件。

Cloudflare 作為網站基礎設施提供商,可能依其服務運作處理請求層級的技術資料;Pelu 自己的統計資料只看得到匿名加總。

兒童隱私

Pelu 是給開發者使用的工具,設計對象為一般成年使用者。即便兒童使用,我們也不會蒐集任何資料——因為我們不向任何人蒐集資料。

完整移除 Pelu

想完全清除 Pelu 在所有裝置上的痕跡,三個步驟就好:

  1. 在 iPhone 上長按 Pelu 圖示 → 刪除 App。
  2. 在 Mac 上把 Pelu 拖到垃圾桶。
  3. (選用)打開 iPhone 的「設定 → Apple 帳號 → iCloud → 管理儲存空間」,找到 Pelu,點刪除資料。

做完上述步驟,Pelu 就完全不存在於你的數位生活中了。我們這邊永遠沒有你的備份。

政策變更

如果本政策有任何實質變更,我們會在此頁面更新「最近更新」日期,並在 app 內的更新說明告訴你。我們不會偷偷改條款。
