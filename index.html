開發者專區

想看原始碼或一起改?

Pelu 的 app 原始碼放在 GitHub。這裡整理開發時會用到的工具、建置入口,以及 fork / 發版前最容易踩到的地方。

TobyWu666/pelu
需要的工具
  • Xcode + Swift 6:需要完整 Xcode,不是只有 Command Line Tools。
  • SwiftPM / xcodebuild:跑 core tests、iOS app、Mac menu bar app 與 Widget。
  • Apple Developer:App Group、CloudKit container、Signing 與 App Store Connect 都會用到。
  • Sparkle / notarytool:Mac 發版需要 Developer ID、notarization、DMG 與 appcast。
先注意
  • Fork 後要換成自己的 Bundle ID、App Group 與 CloudKit container。
  • iPhone 與 Mac 必須登入同一個 iCloud,同步才會出現資料。
  • Production CloudKit schema、PrivacyInfo.xcprivacy 與 App Group 權限要在送審前確認。
  • Pelu 沒有自家後端;請不要加入分析、廣告 SDK,也不要把使用者用量送到第三方服務。

常見問題

想知道的事

Pelu 真的看不到我的資料嗎? +

是。Pelu 沒有任何伺服器,你的用量資料只放在你自己的 iCloud,只有你的 Apple ID 看得到。我們既看不到、也不持有任何使用者的資料。

需要註冊帳號嗎? +

不用。Mac 與 iPhone 各下載一次 Pelu,登入同一個 Apple ID,就會自動同步。我們沒有帳號系統。

同時在多台 Mac 使用會看到什麼? +

Pelu 預設你可能用同一個帳號在多台 Mac 工作。iPhone、Widget 與動態島會整合顯示最近更新的用量,不會分成多份；你仍可在設定的裝置列表查看已加入的 Mac。Mac 選單列則維持顯示該台 Mac 本機讀到的最新用量。

需要安裝什麼額外的設定嗎? +

第一次啟動時,Pelu 會請你同意安裝一個輕量的 Claude Code statusLine hook(只是寫入用量數字,不會接觸對話內容);Codex 則自動連到桌面 app 或 CLI 提供的官方 quota。同意完之後,你只要繼續工作就好,Pelu 會在背景安靜地把最新數字同步到 iPhone。

會佔用 iCloud 雲端硬碟空間嗎? +

佔用量極少。Pelu 只存放純文字的用量數據,單台 Mac 的資料通常不超過幾十 KB,對你的 iCloud 儲存空間幾乎沒有影響。

會對 Mac 造成負擔嗎? +

不會。Pelu 在背景以極低頻率讀取本機的用量紀錄,CPU 與記憶體佔用幾乎可以忽略,對電池也沒有明顯影響。

需要付費嗎? +

iOS 版目前限時免費下載。Pelu 沒有訂閱、沒有廣告;Mac 搭配元件維持免費下載。
