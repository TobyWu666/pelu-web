App 資訊

關於這個 App

Pelu 是一款 Apple 平台上的 AI 用量監控工具,把 Mac 上 Claude Code 與 Codex 的即時用量, 同步到你的 iPhone、Widget 與動態島。使用多台 Mac 時自動整合最近更新的用量,資料只存在你自己的 iCloud。

快速解答

先看看這幾項

遇到狀況時,通常從這裡開始查比較快。更詳細的步驟在使用教學。

怎麼安裝 Pelu?+
兩步驟:Mac 上下載 Pelu Mac 版,iPhone 上從 App Store 下載 Pelu。兩台裝置登入同一個 Apple ID 即可自動同步。完整步驟見使用教學。
iPhone 看不到 Mac 的資料?+
請確認:(1) 兩台裝置使用同一個 Apple ID;(2) 兩端 iCloud 都打開;(3) Mac 上的 Pelu 處於啟動狀態。完整的排查步驟在使用教學的常見問題。
有多台 Mac 時,用量怎麼顯示?+
同一個 Apple ID 下的 Mac 會列在設定中的裝置列表。iPhone、Widget 與動態島只顯示最近更新的用量；Mac 選單列仍顯示該台 Mac 本機讀到的最新用量。完整說明見使用教學的常見問題。
Codex 顯示為「估算」或「過期」?+
Codex 主要從官方 quota 讀取(透過 Codex 桌面 app 或 CLI 內附的 binary)。當官方 quota 暫時讀不到時,Pelu 會自動退回本機 session 紀錄估算,並在介面標示為「估算」或「過期」。打開 Codex 桌面 app 後,Pelu 通常會在一分鐘內切回官方數值。
Mac 版要怎麼更新?+
PeluMac 內建 Sparkle 自動更新。預設會在背景檢查新版本,你也可以在 Mac 上的「Pelu → 設定 → 更新」改為手動,或按「立即檢查更新」。iOS 端透過 App Store 更新。
需要付費或訂閱嗎?+
iOS 版目前限時免費下載,未來將恢復 NT$60。Pelu 沒有訂閱、沒有廣告;Mac 搭配元件維持免費下載。
Pelu 會蒐集我的資料嗎?+
不會。Pelu 沒有自家伺服器、不蒐集任何資料。在 App Store 申報為 Data Not Collected。完整說明請見隱私政策。
如何刪除 Pelu 與相關資料?+
  1. iPhone 上長按 Pelu 圖示 → 刪除 App。
  2. Mac 上把 Pelu 拖到垃圾桶。
  3. (選用)打開 iPhone「設定 → Apple 帳號 → iCloud → 管理儲存空間 → Pelu → 刪除資料」。

目前狀態
