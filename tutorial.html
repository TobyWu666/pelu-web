開始之前

先確認三件事

Pelu 不需要你做任何進階設定。只要確認 Mac 與 iPhone 都登入同一個 Apple ID, iCloud 是打開的,就可以開始了。

iPhoneiOS 17 或更新
MacmacOS 14 Sonoma 或更新
兩台裝置登入同一個 Apple ID

安裝與設定

兩個步驟就好

兩台裝置各自下載一次,登入同一個 Apple ID,Pelu 就會自動同步。

  1. 1
    Mac

    在 Mac 上安裝 Pelu 搭配元件

    從首頁下載 Mac 搭配元件 Public Beta DMG,把 Pelu 拖進「應用程式」,雙擊打開。Mac 端負責讀取 Claude Code / Codex 用量,並透過你自己的 iCloud 同步到 iPhone。

    • 第一次開啟會看到 Apple 的安全提示,點「打開」就好。
    • 啟動後,Mac 螢幕右上角的選單列會出現 Pelu 的小圖示。
    • Onboarding 會檢查 iCloud、偵測 Claude Code 與 Codex,並請你同意安裝 Claude Code 的 statusLine hook(只寫入用量數字,不會接觸對話內容)。
    • Codex 端則自動找到桌面 app 或 CLI 內附的 binary 讀取官方 quota,不需要你另外設定。
    • Mac 版內建 Sparkle 自動更新,可以在設定中改成自動或手動「立即檢查更新」。
  2. 2
    iPhone

    在 iPhone 上安裝 Pelu

    從 App Store 下載 Pelu iOS 1.0.0,確認你的 iPhone 跟 Mac 用同一個 Apple ID。Mac 端先上傳資料後,iPhone 會自動同步;若尚未有 Mac 資料,app 會停在等待同步狀態。

    • 打開 app 後,通常 5–10 秒就會看到 Mac 那邊的用量數字。
    • app 會詢問是否要開啟「通知」與「Live Activity」,你可以日後再開。
    • 想加 Widget?長按主畫面 → 加入 Widget → 搜尋 Pelu,選小尺寸或中尺寸都可以。
就這樣。之後 Pelu 會在背景安靜運作:你用 Claude Code 或 Codex 時,iPhone 上的用量會自動更新。若你有多台 Mac,同帳號的裝置會出現在設定列表中,主畫面則只顯示最近更新的用量。

Pelu 會顯示什麼

三個你最在意的數字

Pelu 不會顯示對話內容、不會顯示程式碼,只把這三件事講清楚。使用多台 Mac 時,畫面會以最近更新的用量為準。

這 5 小時用了多少?

每個 AI 工具會給你一段 5 小時的工作視窗。Pelu 用一條進度條告訴你已經用掉多少,還剩多久重置。

這一週用了多少?

7 日週期的用量。讓你知道接下來幾天還能寫多少 code,不會莫名其妙撞到上限。

花了多少錢?

每天的花費估算,加上 30 天歷史長條圖,讓你的 AI 預算心裡有底。

小提醒:Pelu 讀的是命令列版的 Claude Code(透過 terminal 啟動),以及 Codex 官方 quota(由 Codex 桌面 app 或 CLI 內附的 binary 提供;若暫時讀不到會退回本機紀錄估算,介面會標示為估算)。網頁版或手機版的 ChatGPT、Claude 桌面 app 普通聊天並不在範圍內。

常見問題

遇到狀況看這裡

iPhone 上一直看不到 Mac 的用量?+

請依序確認:

  1. Mac 和 iPhone 是不是同一個 Apple ID?(設定 → 你的名字)
  2. 兩台裝置的 iCloud 是不是都打開?
  3. Mac 上的 Pelu 是否處於開啟狀態(選單列有看到 Pelu 圖示)?
  4. iPhone 沒有開「低耗電模式」,而且允許 Pelu 在背景更新。

通常打開 Pelu iPhone app 一次就會強制刷新。

Claude Code 顯示 0% 或「無資料」?+
兩種常見原因:(1) 你這 5 小時還沒用過 Claude Code,所以沒有用量可顯示,打開 terminal 跑一段工作後等幾分鐘 Pelu 就會更新。(2) Onboarding 時沒同意安裝 Claude Code 的 statusLine hook,可在 Mac 上 PeluMac 設定中重新啟動安裝精靈即可。
Codex 顯示「估算」或「過期」是什麼意思?+
Codex 預設讀取官方 quota,如果暫時讀不到(例如 Codex 桌面 app 沒開,或 binary 暫時無法啟動),Pelu 會自動退回本機 session 紀錄推算,並在卡片上標示「估算」或「過期」。打開 Codex 桌面 app 或 CLI,Pelu 通常一分鐘內會自動切回官方數值。
Widget 怎麼很久才更新?+
iOS 對 Widget 的更新頻率有限制,這是系統設計。如果差很多,可以打開 Pelu app 一次強制刷新,或關閉低耗電模式試試。
Live Activity 過幾小時就消失了?+
iOS 對單一 Live Activity 設有 8 小時上限,這是系統規則。下次 Pelu 收到新的用量更新時,Live Activity 會自動重啟。
同時在好幾台 Mac 使用會怎麼顯示?+
可以。每台登入同一個 Apple ID 的 Mac 安裝 Pelu 後,都會出現在設定中的裝置列表。iPhone、Widget 與動態島會整合為一份畫面,顯示最近更新的用量；每台 Mac 的選單列仍顯示該台本機讀到的最新用量。
需要付費嗎?+
iOS 版目前限時免費下載,2026-06-04 起為 NT$60。Pelu 沒有訂閱、沒有廣告;Mac 搭配元件維持免費下載。
想完整移除 Pelu 怎麼做?+
  1. iPhone 上長按 Pelu 圖示 → 刪除 App。
  2. Mac 上把 Pelu 拖到垃圾桶。
  3. (選用)打開 iPhone 的「設定 → Apple 帳號 → iCloud → 管理儲存空間 → Pelu → 刪除資料」,把 iCloud 上的紀錄也清掉。
